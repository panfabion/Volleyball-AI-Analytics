# Volleyball-AI-Analytics
本專案是一款為了喜愛排球的玩家所設計的**「排球比賽 AI 戰情分析可視化系統」**。  系統的設計理念不僅僅局限於專業聯賽或大專甲組的頂級競技，更致力於打破傳統昂貴運科設備的門檻，讓一般學生、校園系隊、乃至基層業餘排球愛好者，都能透過最簡單易懂的直觀介面，隨時回顧賽事輪轉走位、個人得失分細節與運動力學數據。  在傳統體育賽事轉播或訓練中，專業級的追蹤系統（如 Hawk-Eye 鷹眼、Catapult 穿戴感測器、SIMI Motion 動作捕捉）多半造價高昂且操作繁複，一般學生與校隊難以普及。 藉由本次生成式 AI 課程作業，我透過 Vibe Coding 的模式，與 AI 深度對話發想規格，初步打造了一款運動科學的互動式戰情分析儀表板。
